# Project primer

Troy Anderson's website presents his work as an author, life coach and media guest through an editorial video homepage and focused content pages. Content is managed in Sanity; code owns composition, motion and responsive behavior.

The current experience has nine visible hero clips drawn from fourteen, six routes including unlinked/noindex Press, a testimonial carousel, Book excerpt/retailer controls, About backstory disclosures, Media playback and a browser-direct contact form. [The handoff](CURRENT_HANDOFF.md) is the current implementation map.

## Principles

- Preserve the approved visual direction: bold typography, gapless video composition and minimal interface chrome.
- Make keyboard, pointer and touch interaction usable; respect reduced motion and provide intentional phone layouts.
- Give editors focused content controls without turning the site into a page builder.
- Preserve content, drafts and the client's ownership of code/media and domain registration.
- Prefer the smallest implementation that meets the requested need; optional future features need explicit scope.
